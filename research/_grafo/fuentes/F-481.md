# F-481 · Revisión de 25 casos de aplicación del Viable System Model / Exploring organizational competencies to implement IT systems using Wardley mapping: a case study

**Autor:** ResearchGate / Design Society (revisión de casos VSM + caso Wardley mapping) · **Año:** 2016-2024

**Rigurosidad:** 🟡 C — literatura de conferencia y casos de acción-investigación; muestra pequeña, sin control

## Resumen

[Pista empírica/negocio] VSM (Beer) tiene 25 casos revisados de los que se derivan patrones comunes de aplicación, incluyendo un caso en una empresa global de software B2B de 9.000 empleados para atender picos de incidentes, prioridades en conflicto y pivotes estratégicos lentos. Wardley mapping se ha usado para entender modelos de negocio en proyectos de gobierno del Reino Unido. Evidencia de aplicabilidad real, no de superioridad frente a alternativas.
