## ⚠️ Nota de método — el repo tuvo el mismo problema que diagnostica

Hasta el 2026-08-14 esta carpeta tenía **dos versiones del Playbook conviviendo**, con nombres que
diferían solo en una mayúscula: `Playbook_del_Asesor.md` y `Playbook_del_asesor.md`. Ni el nombre ni
el contenido declaraban cuál mandaba, y dos documentos del repositorio citaban la vieja.

Es **exactamente el caso de casi-duplicado** que el proyecto documenta como la principal causa de
respuestas inconsistentes en AIDA: dos versiones del mismo tema, ambas plausibles, sin señal de
vigencia. Que le pasara al repositorio que lo está diagnosticando es la mejor demostración de que el
problema no es de descuido — **es lo que ocurre por defecto cuando nada obliga a declarar el
estado.**

**Regla que queda para esta carpeta:** todo documento lleva **fecha y estado en el nombre del
archivo**, y este README es el índice que dice cuál manda.
