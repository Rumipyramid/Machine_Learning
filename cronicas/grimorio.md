# 📕 Grimorio — Registro de fuentes de las crónicas paranormales

> Ledger persistente de las fuentes usadas en las crónicas paranormales. Lo registra y lo
> consulta el skill `/grimorio`; lo alimenta `/aquelarre`. Separado del códice
> (`research/fuentes/codice.md`) para no mezclar este mundo con las métricas del segundo
> cerebro. Iniciado: 2026-10-24.

## Rigor (A-E, misma rúbrica del códice)
| Nivel | Criterio |
|---|---|
| 🟢 A | Académico peer-reviewed, datos primarios, método explícito. |
| 🔵 B | Archivo u organismo oficial, documento público con procedencia. |
| 🟡 C | Investigación con método propio no auditable. |
| 🟠 D | Prensa, documental, TV o blog que cita a otros sin método propio. |
| 🔴 E | Testimonio anónimo, foro, viral, sin origen verificable. |

## Cercanía al hecho (P1-P5)
| Nivel | Qué es |
|---|---|
| P1 | Documento primario contemporáneo al hecho. |
| P2 | Prensa de la época o testimonio registrado poco después. |
| P3 | Testimonio de primera mano, identificado, recogido después. |
| P4 | Relato de segunda mano o recopilación posterior. |
| P5 | Amigo de un amigo, anónimo o viral sin origen. |
| — | Contexto general, no habla del caso. |
